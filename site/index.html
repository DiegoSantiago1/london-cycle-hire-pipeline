Where London's bikes run out, and where to act first

Every 15 minutes the pipeline photographs all of London's public bike stations. Joined with 41 million published trips, it shows which stations run empty or full, when, and how many trips that costs.

The business problem

Rebalancing: bikes flow one way in the morning, the other way at night

Residential stations empty out before work while central ones fill up; in the evening it reverses. An empty station is a trip that never happens. A full one is a rider who cannot return the bike.

How it is built

Data that never stops arriving

Two rhythms: live snapshots every 15 minutes, and trip files that TfL publishes months late. Raw data is stored untouched; everything else is rebuilt from it every day.

header variants in the trip files

Columns in different orders, a file without quotes and with dates like 14/08/2024, station numbers with the leading zeros stripped by Excel. Read by name, never by position; an unknown column stops the load.

Pipeline health · live

How do we know today's data arrived?

Every run writes a record, success or failure. Scheduled runs are compared with the time they should have started: that delay, measured run by run, is the evidence for moving the collector off the GitHub Actions cron.
